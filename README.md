# 往還

問いに答えるだけで回るタスク・アイデア管理ツール。個人用、ローカルWebアプリ、AIなし。
設計の詳細は作者手元の設計書を参照。

現在実装済み(段階1): 常にある入力欄/日付・見積もりの読み取り/問いのカード(いつやる?・朝の持ち越し・朝の順番・今はどう思う?)/いま線と今日の約束(開始・終了・並べ替え)/編集・削除/全文検索/書き出し(md・json)。

## 開発

```bash
npm install
npm run dev
```

http://localhost:3000 を開く。データは `data/reflow.db` (SQLite, gitignore対象) にローカル保存される。
